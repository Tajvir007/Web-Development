Basic CSS

# Inline css

Learnings

  1. CSS is used to style HTML elements.
  2. CSS can be applied inline, internally, or externally.
  3. CSS selectors target specific HTML elements for styling.
  4. CSS properties control the appearance of elements.

What is CSS?

  • CSS stands for Cascading Style Sheets.
  • CSS is used to style and layout web pages.
  • CSS can be applied to HTML elements using selectors.
  • CSS properties control the appearance of elements, such as color, font, spacing, and more.

CSS Basics

  1. CSS can be included in HTML using the <style> tag.
  2. CSS can also be linked externally using the <link> tag.
  3. CSS rules consist of selectors and declarations.
  4. CSS allows for responsive design, making web pages adapt to different screen sizes.
